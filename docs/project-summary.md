# 项目现状总结

更新时间：2026-05-23

## 结论

项目已从“桌面宠物面板应用”的方向，调整为“透明无边框桌宠”的重构路线。

这次调整的原因不是风格偏好，而是当前代码主链路存在结构性问题：

- 生产页面与需求不一致
- IPC 断裂
- 面板 UI 不符合桌宠目标
- 旧脚本和 TS 原型并存，难以维护

## 新方向

当前版本以“最小可运行桌宠”为第一目标：

- 透明主窗
- 无边框
- 常驻桌面
- 托盘交互
- 气泡聊天
- JSON 持久化
- Python LLM 后端可接可降级

## 当前实施范围

本轮重构优先完成：

1. 统一主链路
2. 改造窗口形态
3. 重写透明桌宠页面
4. 接通状态与聊天
5. 修正托盘命令

## 暂缓项

以下内容不作为本轮完成标准：

- 20 种完整资源动画全部接入
- 微信好友系统
- 精细性能压测
- 透明区域像素级穿透

## 结果定义

当你启动应用时，应该看到一个悬浮在桌面的透明宠物，而不是一个带大块 UI 的窗口。这将作为后续继续打磨动画、行为和社交能力的基础版本。
